Starter Trio Finder

Every set of three Pokémon that could work as an alternative starter trio: a closed type triangle, low starting stats, and evolutions that grow into equally strong final forms.

A trio is valid when

  1. Each has one type advantage and one type disadvantage within the trio
  2. Each is unevolved
  3. Each can evolve at least once
  4. Each has a base stat total (BST) of 350 or less
  5. Each final evolution has a BST of 450 or more
  6. The three starters' BSTs are within 10 of each other
  7. The three final evolutions' BSTs are within 10 of each other
How the rules are applied

A has an advantage over B when at least one of A's types hits B super effectively, counting both of B's types. The trio must form a one-way loop: A beats B, B beats C, C beats A, and no one beats the Pokémon that beats them. Type chart is the current one, including Fairy.

"Unevolved" means the first stage of its evolution line, so Pichu counts and Pikachu does not. Only each species' standard form is included. When a line branches, each final evolution is checked separately, so one trio can appear with different final forms.
